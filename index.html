วิธีใช้ / HOW TO USE

  • ครู: เปิดลิงก์นี้บนโปรเจกเตอร์หรือแท็บเล็ต 1 เครื่อง/นักเรียน 1 คน
  • กรอกชื่อ–ห้อง เลือกหัวข้อการพูดที่ต้องการทดสอบ
  • กดปุ่มไมค์ให้นักเรียนพูดตามสถานการณ์ที่กำหนด (30–60 วินาที)
  • AI จะถอดเสียงเป็นข้อความและตรวจคำศัพท์เป้าหมายให้อัตโนมัติ
  • ครูให้คะแนน 3D Rubric ทีละมิติ ระบบสรุประดับ CEFR ให้ทันที
  • กด "พิมพ์ผลการประเมิน" เพื่อบันทึกเป็น PDF ต่อนักเรียน 1 คน

หมายเหตุ AI

  • ใช้ Web Speech API ถอดเสียงพูด→ข้อความแบบ real-time ในเบราว์เซอร์ ไม่ส่งข้อมูลออกนอกเครื่อง
  • รองรับดีที่สุดบน Google Chrome; หากเบราว์เซอร์ไม่รองรับ ครูยังให้คะแนนจากการฟังสดได้ตามปกติ
